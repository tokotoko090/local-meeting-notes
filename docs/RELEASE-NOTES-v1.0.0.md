# Local Meeting Notes v1.0.0 — Windows

Windows 10 / 11の64bit版向けに、インストーラーで導入・更新できる正式版を公開します。

## インストール

Releaseの `LocalMeetingNotesSetup-1.0.0.exe` をダウンロードして実行してください。Git、Python、Node.jsの導入は不要です。FFmpegとアプリの実行環境を同梱しています。インストール後はデスクトップまたはスタートメニューから起動します。

管理者権限は不要です。コード署名は付けていないため、SmartScreenの警告が出る場合があります。入手元が `tokotoko090/local-meeting-notes` のReleaseであることを確認してください。

## 旧版からの更新

アプリの「設定 → アップデート」から確認・ダウンロード・インストールを実行してください。Releaseのインストーラーを直接実行しても更新できます。アンインストールせず、これまでと同じインストール先へ上書きしてください。設定と録音を保持します。

v1.0.0の更新機能は、GitHubが提供するサイズ・SHA-256でダウンロードしたファイルを検証し、実行直前にも再確認します。録音・文字起こし・入力テスト中は更新できません。

## 文字起こし

NVIDIA GPUがなくてもCPUで利用できます。対応GPUを使う場合はNVIDIAドライバーと、設定画面から導入するCUDA対応コンポーネントが必要です。CUDAの実行に失敗した場合は通知してCPUへ切り替えます。

標準モデルは `large-v3-turbo` です。選んだモデルは初回利用時に取得するため、インターネット接続と空き容量が必要です。取得後はローカルキャッシュを利用します。取得に失敗しても録音は残るので、接続を確認して「保存済み音声」から再実行してください。

## 検証範囲

Windows実機と、開発用PATHを外した隔離インストールで検証しました。新規導入、旧版ファイルからの上書き、設定・録音の保持、マイク／PC音声の録音停止、CPU／CUDA文字起こし、日本語の保存先、プロンプト編集・コピー、再起動を確認しています。

別PC、Windows Sandbox、Windows 10実機での確認は未実施です。Mac版の配布物はこのReleaseに含めません。ソース内のMac実装は維持しています。

インストーラーのSHA-256とソースコミットは、添付の `windows-manifest.json` と `release-manifest.json` で確認できます。
